# Changelog

## 1.2.0 (2026-10-31), first public release

What you get
- One image from your facts in four graded stages: `compose.py new <slug> --scope quick --medium image`, and `compose.py next` prints each next command.
- Each piece looks different from the last: the direction, colours, type and layout are dealt away from what you made before.
- Colour plans keep your brand's hues: pass your tokens file with `compose.py new <slug> --brand <tokens.css>`.
- Checks before you post: type size measured as drawn, contrast, overlap, broken links, missing images and fallback fonts fail, and page 1 must lead with your hook, number or object.
- Two install lines: `/plugin marketplace add goofypluto999/atelier`, then `/plugin install atelier@mansions`. For claude.ai, two zips on the release page.

The detail follows.

Install
- The plugin is `atelier` in the `mansions` marketplace. The command is `/atelier:atelier`; the agents are `atelier:story-editor`, `atelier:art-director` and `atelier:copy-critic`.
- For claude.ai: `atelier-skill.zip` (the whole skill folder, with its LICENSE and CREDITS.md) and `humanizer-skill.zip`, built with `git archive` from committed files ([CONTRIBUTING.md](CONTRIBUTING.md)).
- Playwright is pinned to 1.63.0 for Node and Python. `attention.py` needs Pillow 10.3 or newer.
- Quick start: Pillow goes into a virtual environment (PEP 668), with lines for bash or zsh, Git Bash on Windows (`python -m venv .venv`, `. .venv/Scripts/activate`) and PowerShell, where the venv's Python runs pip directly because the default execution policy blocks Activate.ps1. CONTRIBUTING's setup uses a venv too. The `S` lines read `CLAUDE_CONFIG_DIR` when it is set. In Windows PowerShell the install lines use `npm.cmd` and `npx.cmd`, because the default execution policy stops the `.ps1` files that `npm` and `npx` start.
- plugins/mansions/README.md, so a copy without git validates.

The composer ([references/composer.md](plugins/mansions/skills/atelier/references/composer.md))
- `scripts/compose.py`: eight graded stages (atoms, lenses, angles, genome, sections, copy, visual, final), each with a rubric and a threshold. Below it a stage is recreated or revised; after 3 graded attempts (2 for the final stage) it goes to a person.
- `compose.py next` prints the one next command with absolute paths, and every command has `--help`.
- Quick scope (`new --scope quick`): four stages (atoms, angles, genome, visual) for one image. Only the visual stage needs a critic.
- `deal <slug> genome --pin axis=value` fixes an axis before the deal in any scope (for example `--pin register=warmth`); later deals of the piece keep it.
- Design scope (`--scope design`, `adopt`, `--pin`): a host system with its own angle gate and critics uses the composer for the dealt design, the colour plan and the memory only.
- A critic-graded stage needs the critic's verdict file (`--evidence`). Type the critic's scores into `--scores`; compose.py refuses numbers that differ from the verdict file and recomputes the total. A FAIL verdict never passes and counts as an attempt.
- The visual grade is bound to its piece: its render folder and the verdict's `## <slug>` heading; every grade records the verdict file's sha256, and a passing grade also records the sha256 of `visual.html` and the pages ([Rules the checks enforce](README.md#rules-the-checks-enforce)).
- `compose.py scaffold <slug>` writes the page with absolute links to the tokens, fonts and `palette.css`. For an image or a carousel it is a composition start, not a copy of the direction's specimen: the grid, the dealt type and the colour roles, each page set up for its dealt layout word. The art-director judges distinct against the specimen, so the specimen's frame and sample words stay out of the page, and the deal never gives page 1 the specimen's own layout. The genome and visual worksheets name the frame to leave, the specimen's stock parts that must not appear unchanged (data/directions.json "stock", listed in references/directions.md), each page's layout, the object atom and the word budget, and say to build the direction's device out of the topic's own object. A wide display face (`hook_scale` in data/type_pairings.json, measured) sets the start's sample hook smaller, so the start passes its own audit in all 12 layouts for every local pairing. A film still starts from its motion specimen.
- `scaffold` points the direction's colour tokens at the roles in `palette.css` and links your `new --brand` file after tokens.css, so your colour plan and brand colour the page. `next` prints the `palette.py` line first when `palette.css` is missing.
- The page carries an empty logo slot. `scaffold` fills it from your brand file's `--logo` (`--logo-on-dark` on a dark or colour-field ground), or removes it and says why. `deliver` adds the cover to the layout memory.
- Play and perspective as data: 44 play operators, 24 lenses, 30 formats with overuse scores, 9 registers, and the hooks, closes and layout words ([data/](plugins/mansions/skills/atelier/data)).
- A hook or close that needs material (a confession, a dated moment, a quote, an artefact, a number; the closes "changed" and "next-test") is dealt only when a sourced atom carries it, and the genome worksheet says what it left out. Every command finds the nearest `.atelier` at or above the current folder, so `next` works from a page's folder. The quick visual stage asks for the post text the critic checks the page against.
- One memory, `.atelier/history.jsonl`. The dealer pushes away from recent choices harder as memory grows, and the same topic twice gets no operator, lens, format or direction it had before ([tests/test_composer.py](plugins/mansions/skills/atelier/tests/test_composer.py)); [tests/test_diversity.py](plugins/mansions/skills/atelier/tests/test_diversity.py) measures the spread over 20 or more pieces.

Colour ([references/colour.md](plugins/mansions/skills/atelier/references/colour.md))
- The default look is generic: `tokens.css` holds a neutral palette. The Mansions Agency's palette and logo are an optional theme, `assets/themes/mansions.css`: load it after tokens.css or pass it with `--brand`.
- `scripts/palette.py`: OKLCH colour plans set by the register, with harmonies, arcs, and contrast and colour-vision checks. It keeps the brand's hues, says when the register overrides the harmony, and warns near a generated-design cluster.
- Without `--brand`, a paper ground is never dealt a serif display face.
- Without `--brand`, each piece gets its own palette, not the specimens' colours: the register gives the accent a hue band and the neutrals a hue (data/colour.json "own"), the dealt harmony and arc pick the place in the band, and every ground and text colour is kept 0.04 OKLab or more from the specimens' (assets/tokens.css), every accent 0.10 or more, and every ground out of the two colour clusters. Tested over every register, harmony, arc and ground, and over 20 dealt genomes.
- Register warmth's own palette is warm in its neutrals and in its accent (a madder red, chroma 0.05 to 0.10, as recipe warm-neutrals asks). A brand keeps its own neutrals and hues.

Drawn films ([references/art-motion.md](plugins/mansions/skills/atelier/references/art-motion.md))
- `ART.film` (`assets/lib/art-motion.js`): a canvas world under the page's words, with a camera that pushes, glides and pulls, springs, a film finish and the page's palette.css colours. It sets `window.seek(t)`, so `motion.mjs` renders it and the audit, attention and video checks read it as any other motion page.
- Five drawing files from huashu-art-motion (alchaincyf, MIT), vetted before copying and pinned by blob hash in [vendor/MANIFEST.md](plugins/mansions/skills/atelier/vendor/MANIFEST.md). Its skill file, references, Python scripts, renderer, voice cloning, fonts and media were left out; [docs/INTAKE.md](docs/INTAKE.md) is the adoption process, with this tool as the worked example. The vet's conditions bind its use, among them no studio characters, no imitation of a living artist and no likeness in public posts (vendor/MANIFEST.md).
- `motion.mjs --out <dir>`, and a film may load local files only: any other request is blocked and fails the render.
- `video_check.py` looks for still stretches on a quarter-size, blurred copy, so film grain no longer hides a dead beat.
- The audit judges text over a canvas on the rendered pixels.
- [tests/test_motion.py](plugins/mansions/skills/atelier/tests/test_motion.py): the vendored blob hashes (every tool), no code that starts uv, npx or pip, a fixed-seed film rendered twice, a still stretch under grain, a blocked remote request. Without Playwright, every render check prints SKIP and the test passes.
- A drawn object can lead a film's poster: mark it with an empty element that follows it (`data-role="object"`, placed each frame from `CAM.toScreen`; references/art-motion.md). `render.mjs --audit --seconds --poster` writes the boxes at the poster time to boxes.json, and attention.py and cvd.py read poster.png with them. motion.mjs takes the nearest frame for the poster (a poster time halfway between two frames wrote no poster.png).

Checks ([Rules the checks enforce](README.md#rules-the-checks-enforce))
- `render.mjs --audit` writes the PNGs and fails on type floors measured as drawn (32 px, 36 px condensed, 22 px fine print), contrast, overlap, text off the page, broken links, missing images and fallback fonts.
- It warns, never fails, on AI-look tells, among them fake product chrome (window dots, live dots, NEW or BETA badges), pill tags and too many corner radii, panels nested three deep, and raw colour values outside the tokens. Mark a deliberate use with `data-allow="chrome"`, `"pill"`, `"nested"` or `"colour"`; `--raw-max N` sets the raw-colour limit (default 6). It also warns when the page's `--accent` paints 5% or more of the page, text left out, and when display type leaves one word alone or ends a line on a small word, and when a page carries more than 45 words, with the number to cut (the word budget in references/copy.md). Every specimen headline is balanced, with small words tied to the next; the kitchen-rail tickets sit inside the 80 px margins and set their words in the text face.
- `render.mjs --audit` fails a rule through text: a border (a table's, a cell's, a box's) or a thin bar that crosses the middle of a line of text and shows on the render. `data-allow="over"` marks a deliberate strike.
- `attention.py`: page 1 must be led by the hook, the number or the object. A logo or an unmarked element never leads, and a logo under 3:1 against its ground fails. A rendered page with no data-role at all fails it too, as it fails the audit.
- `contact_sheet.py` reads only `page-NN.png`. `attention.py` and `cvd.py` read every `page-NN.png` and, for a film, `poster.png` too. `cvd.py` ends with `cvd: PASS` or `cvd: WARN`.
- `copy_lint.py` warns on repeated words; `--brand` and `--allow` keep names and the subject's own terms out of the count.
- huashu-design's `design_lint.py` checks template habits and repeated looks in the visual stage. It is optional: it needs Python Playwright 1.63.0, which the quick start does not install.

Critics, examples and sources
- Three critic agents: `story-editor` (atoms, angles, sections), `art-director` (rendered pages) and `copy-critic` (words), with calibration sets in evals/anchors and evals/angles and `scripts/calibrate.py`.
- The art-director writes `reads as: <two words>` after a 2-second look, scores the rubric's six visual criteria and ends with a verdict line and a scores line. It counts every drawn quantity against its label and checks every label at 360 px. With nothing in memory, it judges "distinct" against the shipped specimens and the clusters in references/tells.md.
- The references cover which number is big, dated numbers and honest gaps, one state with one colour, reference works in the brief, crutch words, one grade for photographs ([references/imagery.md](plugins/mansions/skills/atelier/references/imagery.md)) and right-to-left pages.
- 19 direction specimens, a 6-page ledger carousel and a 9:16 reel as worked examples, all with sample content.
- Vendored, pinned and licensed ([vendor/MANIFEST.md](plugins/mansions/skills/atelier/vendor/MANIFEST.md)): parts of taste-skill, huashu-design, brag and superpowers, Anthropic's frontend-design and canvas-design, a 29-family OFL font library and the humanizer skill. [CREDITS.md](CREDITS.md) also lists Uncodixfy (cyxzdev, MIT) and the author's own design notes.
- LICENSE and CREDITS.md are copied into the skill folder, so a plugin install and the claude.ai zip carry them.

Checks added after the first runs (the critics' repeat faults, each with a test: tests/test_composer.py `r12_tests`, or tests/test_palette.py checks P13 and P14)
- `render.mjs --audit` warns, before any critic sees the page, on five faults the art-director charged: `phone read` (text under 36 px, or under 40 px in a weight under 500, fine print included; the page line now gives the smallest size with fine print), `claim twice` (a line that repeats the hook's words), `wrapped run` (identical marks that wrap and leave a short last row), `hairline accent` (an accent mark drawn under 8 px) and `empty cell` (a cell mostly empty beside a full one). The composition start sets its own source line at 36 px in weight 500.
- `palette.py`: a piece's own palette keeps its grounds 0.04 OKLab past a tells cluster's edge and 15 degrees past its hue range, and its accent 0.20 OKLab from the page's text at 4.5:1 or more on the ground.
- `compose.py`: each visual attempt is kept with its page, renders and verdict in `.atelier/pieces/<slug>/attempts/visual-<n>`, and after a FAIL `next` names the best attempt so far, its verdict's numbered fixes and its keep line. Printed commands use the Python that runs compose.py (`python3` where there is no `python`). With no `--brand`, scaffold says so when it removes the logo slot.
- `layout_memory.py check` run from a page's folder finds the project's covers (it said "PASS against 0" there) and no longer makes an empty `.atelier`.
- The six fixtures for fake chrome, pills, nested panels, raw colours, data-allow and repeated words are asserted by a test.
- Node 20 or newer: Playwright 1.63.0 stops below 20.

Checks added after the second run, with tests in tests/test_composer.py, tests/test_motion.py and tests/test_palette.py
- `render.mjs --audit` warns on a `faint mark` (a mark with no text under 3:1 against the ground behind it, WCAG 1.4.11) and a `thin stroke` (display type whose strokes are under 2 px on a phone and under 6.5% of its size). Both were charged in the second 30 Oct run; each has a planted fixture and a twin that must stay quiet (tests/test_composer.py `r13_tests`). A faint mark is measured against the ground behind its own drawn shape: a small shape in its colour, such as the line under a dot, or a shape smaller than the mark is not its ground (tests/test_composer.py `faint_twin_tests`). The departure-board flaps and the specimen-label sheet are marked as texture (`data-allow="faint"`), and forecast's grey dots reach 3:1.
- After scaffold, `compose.py next` names the page scaffold wrote instead of telling you to scaffold again.
- test_palette.py checks P13 and P14 judge the palette.css that palette.py writes, so on the code before their fix they fail on the defect, not on a TypeError or an AttributeError.
- `render.mjs --audit` checks a film past its first frame: every hard rule but the cover's hook rule runs again every half second of the film and at the poster time. The length comes from `--seconds N` (with `--poster T`, as for motion.mjs), else from `ART.film`, else from the CSS animations; with none, the audit checks the first frame and says so. The audit line scaffold prints for a film carries `--seconds 8 --poster 7`. A page that throws an error at a later time gets one FAIL line with the time and the message, not a stack trace.
- The audit reads every CSS colour form. Chromium computes `color-mix()` and relative colours as `oklab()`, `oklch()` or `color(srgb ...)`, which the audit used to skip, so text in such a colour was never judged for contrast.
- No direction fails the audit on a palette it can be dealt. test_composer sweeps all 2,550 pages of the own palettes (every register, harmony and arc on each ground, 6 pages) and audits each of the 17 directions on the pages where a role it maps is darkest, lightest or least readable: 148 renders. The fixes it needed: field-notebook's timestamps are set in ink (in accent they fell to 4.0:1 over the grid on 14 of 40 own palettes); departure-board's letters stay light on its black board, and index-card's ink stays dark on its white card; kitchen-rail's WAIT stamp and departure-board's off flap take the ground colour on the accent; specimen-label's label, the diff pane and colour-chapters' third field step away from the text instead of toward black or white.
- A scaffolded carousel passes its own audit on every page. Each later page's heading carried the format's job at display size ("Page 4: the consequence."), and in the map layout's half-width hook column a long job word crossed the object's border and ran off the page: 1 run of 3 of test_composer failed on it. The heading is now "Page 4: its hook." and the job opens the proof line. Seeded sweeps, before and after: index-card 4 of 120 carousels failed, now 0 of 120; the 19 other carousel directions 0 of 228 both times; every later page of the 13 carousel formats in each local pairing and each of the 12 layouts, 20 of 9,072 failed, now 0. test_composer `r11_tests` scaffolds and audits three seeded index-card deals that put the map layout under a long job on page 4.
- Every test that deals or delivers runs in a project of its own. A deal weighs the project's memory, and the unseeded pieces other tests delivered into the one shared project moved seeded deals from run to run: three tests failed that way, a quick-scope hook test, the specimen render test (1 of 2 runs) and the own-palette test (1 of 5 runs). test_composer gives each of its 19 test groups (the core group and 18 more) its own project (`own_project`), test_diversity uses one too, and `run()` refuses a deal, a delivery or a coverage read in a project the running test does not own; a test of the guard plants all three.
- On Windows the commands compose.py prints start with `& `, the form Windows PowerShell runs, except in Git Bash and MSYS2 (they set `MSYSTEM`), which get the bash form. test_composer prints a line in each environment and runs it as printed: in PowerShell, and in Git Bash with `MSYSTEM` set. `next` prints every command on a line of its own, so a whole-line copy runs as printed, and `choose` prints the step `next` gives (after a RECREATE grade, the deal again, not a genome deal that refuses). So does every other full command compose.py prints, in its output, its error messages and its `--help` example: the label ends its line and the command sits on the next one. Worksheet prose still names some commands inside a sentence; the angles worksheet's choose line sits on a line of its own. A grade line that asks for the swap test ends with `--swap <pass-or-fail>`: left unedited, it fails to parse in bash and in PowerShell, so no grade is recorded.
- tests/test_motion.py checks every tool section of vendor/MANIFEST.md against its own folder, commit and licence, checks the folder's `.gitattributes` and the tool's CREDITS row, fails on a file under vendor/ that no section lists, and scans every code file a section lists. A second tool joins with no test or script edit: a fake one, registered in a temp copy, passes, and fails without its CREDITS row. docs/INTAKE.md step 6 lists the files a tool touches.
- vendor/MANIFEST.md pins every vendored file by git blob hash, the five older tools and the humanizer skill too (59 files). Checked against each upstream tree at its commit: 57 of 59 are the upstream blob; huashu-design's design_lint.py carries the two Atelier patches; Anthropic's canvas-design SKILL.md matches no upstream version, so its local blob is recorded and the section says so. Each folder has a `.gitattributes` (`* -text`), so the bytes, and the hashes, hold on a Windows checkout. Each tool's CREDITS row carries one credit line, "<what> adapted from <repo> by <author>, commit <sha>", and test_motion checks the form.
