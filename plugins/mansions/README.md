# mansions: the Atelier plugin

This folder is the `atelier` plugin of the `mansions` marketplace, by The Mansions Agency.

- `skills/atelier`: designs social images, carousels, slides and short videos in HTML, renders them on your machine and checks them before you post. Start with its SKILL.md.
- `skills/humanizer`: rewrites long copy that reads as AI-written (blader, MIT).
- `agents`: three critics, `story-editor`, `art-director` and `copy-critic`.

Install it in Claude Code:
```
/plugin marketplace add goofypluto999/atelier
/plugin install atelier@mansions
```
On Claude Code 2.1.275 or later, one line also works: `/plugin install atelier --marketplace goofypluto999/atelier`.

Requirements and the full guide: the README.md at the root of the repository, https://github.com/goofypluto999/atelier. Licence: MIT (`skills/atelier/LICENSE`); fonts under SIL OFL 1.1.
