# Colour plan

Register **craft-pride**: quiet satisfaction in a clean mechanism. Recipe `tight-value-precise-accent`: {"ground": "paper or dark", "value_span": "narrow", "accent_C": [0.08, 0.14], "harmony": "monochrome"}.
Harmony **monochrome** (hue offsets [0]): rigour, calm, strong brands. Risk: flat without a lightness range.

harmony split overridden by register craft-pride: recipe tight-value-precise-accent is monochrome, so one accent hue applies and there is no accent-2.

Arc **steady**: same ground throughout.
Ground: **paper** (the direction's ground; the arc moves from it).
Hues: this piece's own palette (no --brand): the register's band gives the accent and the harmony adds its other hues. Accent 151 deg.

Why: lightness: ground and accent lightness set the mood before hue does (Valdez and Mehrabian 1994, J Exp Psych: General; strong for lightness-pleasure). chroma: raise chroma for energy on one element; lower it for calm and rigour (Valdez and Mehrabian 1994; medium). temperature: shift temperature across a piece to move from tension to calm or the reverse (long design tradition; experimental support mixed; treat as convention). contrast-range: set the value span per register (design convention, consistent with fluency research).
